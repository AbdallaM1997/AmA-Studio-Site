# AGENTS.md

Instructions for coding agents (Codex and others) working in this repo.

- Project guide and **brand rules**: read `CLAUDE.md` first and follow it exactly.
- Task recipes live in `.claude/skills/<name>/SKILL.md`. Read the matching one before starting:
  - social media posts, Reels, banners, captions → `.claude/skills/social-post/SKILL.md` (strategy in `marketing/PLAN.md`)
  - add a game → `add-game`, news post → `add-news-post`, launch a game → `launch-game`, motion → `new-animation`
- Before saying a site change is done: `npm run check:data && npm run build`.
