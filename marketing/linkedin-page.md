# AmA Studio — LinkedIn Page kit

Everything to type and upload, in the order LinkedIn asks for it.
Pictures are in `marketing/out/linkedin-page/` (make them again with `npm run social -- profile-picture page-covers hello-from-ama-studio kinfold-is-coming`, then copy).

LinkedIn is for the studio as a business: launches, milestones, hiring, partners, and later the services (event games, AR/VR). English only, about one post a week.

---

## 1. Create the Page
You need your own personal LinkedIn profile first (the Page is managed from it).
LinkedIn → **For Business** (top right, the grid icon) → **Create a Company Page** → **Company**.

| Field | What to put |
|---|---|
| Name | `AmA Studio` |
| linkedin.com/company/ | Only the end part: `amastudio-games` (the one in use: https://www.linkedin.com/company/amastudio-games/). `amastudio` was taken. Lowercase letters, numbers and hyphens only, no dots or slashes. |
| Website | `https://amastudios.net/` |
| Industry | `Computer Games` (type "games" and pick it) |
| Organization size | Pick the true one: `0-1 employees` or `2-10 employees` |
| Organization type | `Privately held` (or `Self-employed` if the studio is just you) |
| Logo | `01-logo.png` |
| Tagline (max 120 characters; this one is 83) | `Game studio from Cairo. Small, bright games for everyday breaks. Serious about fun.` |

Tick the box that you're allowed to act for the company, then **Create page**.

## 3. Page info
Page → **Edit page** (the pencil, or Admin tools → Edit page).

**Overview / About** (max 2,000 characters):
```
AmA Studio is a game studio based in Cairo, Egypt. AmA stands for AmAzing, and that is the bar we set for every game.

We make small, bright games for everyday breaks: easy to learn in a minute, fun for months. Friendly worlds, clear colors and no dark tricks. Games that respect your time. Built in Unity and tested until they feel just right.

Our first game, Kinfold, is a category card puzzle set in Egypt, coming to iOS and Android in English and Arabic.

Players, press and partners: info@amastudios.net
```

**Specialties** (add one at a time):
```
Mobile games
Puzzle games
Casual games
Game design
Unity
Game development
```
Add `Event games`, `AR / VR` and `Branded games` when the services go live on the site.

| Field | What to put |
|---|---|
| Location | Add a location → Cairo, Egypt. City only; leave the street empty unless people can visit. Tick **Primary**. |
| Founded | The year you started the studio (or leave empty). |
| Phone | Leave empty unless you have a studio number. |
| Custom button | `Visit website` → `https://amastudios.net/` (when Kinfold is out: `Learn more` → the store link or `https://amastudios.net/games/kinfold/`) |
| Hashtags (Community hashtags, if shown) | `GameDev`, `IndieGame`, `MobileGames` |

## 4. Link yourself to the Page
On your **personal** profile → **Add section** → **Add position**:
- Title: `Founder` (or your real title)
- Company: type `AmA Studio` and pick the Page with the yellow logo (so the logo shows on your profile)
- Location: Cairo, Egypt

LinkedIn then asks if you want to share it. Say yes: that post is the first thing your network sees.

## 6. Invite people
Page → **Admin tools** → **Invite to follow**. LinkedIn gives free invite credits each month; invite people who'd care (game devs, friends in tech, Cairo creative people).

From your personal profile, share Post 1 with a line in your own words, e.g.:
```
I started a game studio. AmA Studio makes small, bright games for everyday breaks, and our first game, Kinfold, is coming soon. Follow the page if you'd like to see it.
```

## 7. Settings worth doing once
- Turn on **two-step verification** on your personal LinkedIn account (it protects the Page).
- Add a second admin you trust (Admin tools → Manage admins), so you never lose access.
- When the Page has its URL, ask Claude: *"Add my LinkedIn page to the site: https://www.linkedin.com/company/..."*.
- Weekly post ideas: *"Write this week's LinkedIn post about the studio and make the landscape image."*
